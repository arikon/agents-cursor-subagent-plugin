# Codex Cursor Subagent Plugin

Прототип локального плагина Codex, который запускает установленный `agent acp` и предоставляет его как интерактивного субагента через MCP.

В `.mcp.json` намеренно указаны абсолютные пути к Node.js и скрипту текущего проекта: Codex запускает MCP без login-PATH и в этой версии не раскрывает `${PLUGIN_ROOT}` в аргументах MCP. Перед переносом на другой компьютер замените оба пути.

## Модель взаимодействия

`Codex → MCP-плагин → Cursor ACP (stdio JSON-RPC)`

Плагин не использует `cursor-agent --yolo`, файловый IPC или автоматическое подтверждение команд. Сессия Cursor создаётся отдельно, задача запускается асинхронно, а вопросы, планы и разрешения остаются ожидающими до явного ответа через инструменты плагина.

## Требования

- Node.js 18+;
- установленный Cursor Agent (`agent`) и выполненный `agent login`; для нестандартного пути задайте `CURSOR_AGENT_COMMAND` в окружении MCP-сервера;
- Codex с поддержкой локальных плагинов/MCP.

Для локальной проверки:

```sh
node --test tests/mcp-smoke.test.mjs
```

## Установка для разработки

Подключите каталог этого плагина как локальный plugin source в Codex. После загрузки будут доступны инструменты `cursor_start_session`, `cursor_send_prompt`, `cursor_session_status`, `cursor_answer_question`, `cursor_answer_plan`, `cursor_answer_permission`, `cursor_cancel` и `cursor_close_session`.

Передавайте `cwd` отдельного worktree для любой задачи, которая может изменять файлы. По умолчанию используется режим `ask`; перед изменением файлов явно выберите `agent`.
