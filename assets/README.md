# Cursor icon

`cursor.png` is the unmodified 192×192 icon from
[Cursor's official website](https://cursor.com/marketing-static/icon-192x192-light.png),
retrieved on 2026-09-08. See the [Cursor brand guidelines](https://cursor.com/brand).
The artwork belongs to Cursor and is not covered by this repository's code license.

The Codex manifest uses this asset for the composer icon and plugin logo. Its
opaque light background keeps the mark visible in both light and dark themes.
The same asset is shipped with the Claude Code distribution, but Claude Code's
[documented plugin manifest](https://code.claude.com/docs/en/plugins-reference#plugin-manifest-schema)
does not currently provide a custom icon field.
